# 新训练证据的中文整合稿

`main.tex` 是现有中文论文的独立补充稿，保留原稿不动。它区分感知训练、
实体记忆、同一步数控制与最佳检查点比较。机制诊断152项及补充重复8项均已完成复算；
记忆对照两个检查点各129条序列均已完成，184份状态和40项指标已独立复算。新段落使用本轮实际权重结果；
不属于可直接投递的 CVPR 投稿包。

`formal_table.tex` 从已审计的正式结果生成，单位为百分比。其余 CSV 使用 0–1 比例。
正文已撤回“充分统计量”和无条件“固定更新成本”的表述，改为紧凑实体描述、
固定状态/关联规模，并说明局部感知仍依赖输入点数。

在本目录编译：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

引用核验来源：ReScene4D 作者项目页、RIO 的 CVF 2019 论文页面与原论文。
新参考文献中的 RIO 页码按 CVF 更正为 7658–7667；原稿的 7657–7666 未原地修改。
本轮没有对原稿其余参考文献声称完成核验。

章节整合依据：先定义对照和固定总体，再说明精度变化及其归因边界，最后给运行限制。
写作参考采用 CVPR 的实验组织方式与 VGGT 示例卡的输入/输出优先结构，未借用其技术主张。
记忆、机制和运行限制均已整合；完整投稿文稿仍需补齐科学证据，并通过独立科学审查与投稿格式检查。

`mechanism_results.tex` 保留收益与损失、采样覆盖零差异和梯度连接性的边界。
`runtime_repeat_results.tex` 明确记录固定新进程协议仍出现数值差异；
两个输入上的AP一致不等价于逐张量可重复，也不构成独立训练复验。
