# 固定求和顺序的评测修正

六组 seed146 模型各完成 400 步训练，训练版本仍为冻结的 C3。原始 RUN_LOCK、14 项训练数值源代码、24 个阶段检查点和已产生的结果保持原样。预算与实际费用仍使用同一份原始账本，不重置已消耗额度。

原始新一轮 M0 CAL 三次复测最大 AP 波动为 2.888917922973633 个百分点，超过原定 0.2 门槛；这三份结果完整保留，不能挑选或替换其中某次。该大幅异常的因果来源仍未确定。

小样本诊断发现分组均值产生微小浮点差异。仅将 `AdaptiveScatter.mean_scatter` 改为按稳定顺序分组后的 `segment_csr` FP32 算术均值，三次独立完整 CAL 对照的 84 个输入、197 个阶段的输入/原始预测摘要和 AP 完全一致，AP 波动为 0。对照使用原有诊断摘要；正式评测仍须重新验证。

`EVALUATION_POLICY.json` 单独冻结新增评测入口、求和实现、调度入口及相关依赖的代码 SHA，明确记录训练与评测两条来源链。只有专用评测/P5 子进程安装该求和实现；训练子进程继续使用原始 C3 代码。每份正式评测 STATUS/RESULTS 从首次写入起均包含策略 SHA，官方充分统计量的内容和算法保持不变。

新结果写入私有运行目录的 `policies/stable-mean-v1/evaluation`，原始未通过门槛的结果仍留在原目录。三个新正式 M0 CAL 复测全部完成并满足同一 0.2 个百分点门槛后，才能继续评测已有 100/200/300/400 步检查点。CAL/SEL/PB、选择、配对 bootstrap 和 P5 使用同一冻结策略；不得混入未标记或其他策略的结果。

已有训练不重复执行。消融、四点选择、guard、seed147 条件复验、确认集和发布审查要求保持原有科学含义。这里尚不声称原始大幅异常的根因已解决，也不声称候选方法取得性能增益。
