## 问题与候选机制

检验历史实体是否能在首个掩码产生前，凭当前特征检索到其当前位置并注入提示。M4–M6 的全局检索先于首个掩码；M2 的适配读取发生在首轮 hlevels 之后。当前候选置信度不决定是否检索，最多 32 条历史提示，100 个查询中至少 68 个保留发现新对象的机会。空历史保留原父路径。几何摘要来自已接受预测，仅用于检索/提示，不用于强制身份关联。
普通记忆注意力、持久 query 或查询传播本身不作为首次创新。SAM-V 的解码条件、MOTR 的查询传播和 S4VY 的持久查询仅为近邻机制边界；本轮没有复现外部系统，没有引入 RGB 教师或新基础模型。
