# Sonata Second-Perception Code Audit

Audited at start commit `e5d7f4e96fedc76c0c6d414ab293f54909c61df3`.
"New path" means Sonata-specific validation or configuration is required; it
does not authorize changing the frozen P2/V3 semantics.

| File | Role and contract | Current assumption | Disposition and scientific risk |

| `conf/backbone/sonata.yaml` | Instantiates `models.PointceptBackbone` for `facebook/sonata`, `enc_mode=False`, standard decoder serialization. | `name` may be a model alias or local file. | Reuse via Sonata config with verified local `name`. Remote alias would use mutable `main` and is forbidden. |
| `models/pointcept.py` | `PointceptBackbone` loads config/state, runs encoder/decoder, selects decoder serializations, and implements `temporal_overlay`. ## Audit Decision

The existing model/data runtime is structurally reusable, but formal P2 identity
and V3 hard-coded roots are not. The minimum defensible implementation is a
Sonata-specific provenance/preflight/callback/training wrapper plus narrowly
parameterized or wrapped evaluation code protected by frozen regressions.
