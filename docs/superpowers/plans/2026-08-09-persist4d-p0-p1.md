# Persist4D P0/P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce an evidence-backed P0/P1 stage gate for the official ReScene4D code at commit `fb2fe42`, using native 3RScan sequences at horizons 2, 3, 4, and 5 on one NVIDIA A40.

**Architecture:** Keep the official preprocessing, loader, Concerto backbone, ReScene decoder, and loss path intact. Add small command-line audit/profiling tools around those interfaces, with pure functions for unit testing and integration checks against generated sequence databases. Generated artifacts carry source hashes, configuration, hardware provenance, and an explicit GO/NO-GO decision; no Persist4D method code is introduced in this phase.

**Tech Stack:** Python 3.10, PyTorch 2.6/CUDA 12.6, Hydra, official ReScene4D/Concerto/stmetrics, NumPy, PyYAML, pandas, matplotlib, pytest.
