replays for each of M1-u200 and M3-u300. Each full group has equal metric and
prediction records. This finite evidence does not establish the previous
outlier's cause or justify reusing any old metric under a new policy.

The primary agent owns policy semantics, code, tests, admission and review.
The existing GPT-5.6 Luna agent only monitors explicit files and processes.

   Retain the original C3 training sources, run lock, checkpoints and v1/v2
   inference sources. The v3 centroid candidate remains unfrozen.

   runtime. Charge every child to the original ledger and phase cap.

   files. Run relevant new and prior regressions and inspect the complete diff.
